# Runbook prompts

Use actual commands and environments; omit unavailable systems rather than inventing them.

- Symptom, affected scope, and impact.
- Read-only diagnosis with expected interpretation.
- Remediation choices and any required authorization/preservation boundary.
- Exact post-remediation verification.
- Recovery or rollback if remediation fails.
- Real escalation contact, when one is configured.
- Last verified date, environment, and evidence.
